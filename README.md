## 🎯 프로젝트 개요

Product Read Service는 **상품 조회 성능 최적화**를 위한 **읽기 전용 서비스**입니다.

### 🌟 주요 특징

- **읽기 전용 최적화**: 조회 성능에 특화된 서비스 설계
- **MongoDB 활용**: NoSQL 기반 빠른 데이터 조회
- **캐싱 전략**: Redis를 통한 고성능 데이터 캐싱
- **데이터 동기화**: Write 서비스와의 실시간 데이터 동기화
- **검색 최적화**: 전문 검색 및 필터링 기능

### 🏆 핵심 역할

- **상품 조회**: 상품 목록 및 상세 정보 고속 조회
- **공모 조회**: 공모 상품 정보 조회 최적화
- **조각 조회**: 조각 상품 정보 빠른 조회
- **검색 기능**: 키워드 기반 상품 검색

## 🛠️ 기술 스택

### Backend
- **Java 17** - OpenJDK LTS 버전
- **Spring Boot 3.5.0** - 최신 Spring Boot 프레임워크
- **Spring Data MongoDB** - NoSQL 데이터 접근
- **Spring Web** - RESTful API 구현

### Database & Cache
- **MongoDB 4.4** - 메인 조회 데이터베이스
- **Redis 7.0** - 캐시 및 임시 데이터 저장
- **MySQL 8.0** - 메타데이터 저장 (참조용)

### Message Queue
- **Apache Kafka** - 데이터 동기화 이벤트 수신
- **Spring Cloud Stream** - 스트림 처리

### Service Discovery & Documentation
- **Netflix Eureka Client** - 서비스 디스커버리
- **OpenFeign** - 서비스 간 HTTP 통신
- **SpringDoc OpenAPI 3** - API 문서화

### Infrastructure
- **Docker** - 컨테이너화
- **AWS EC2** - 클라우드 배포

## 🚀 주요 기능

### 1. 상품 조회 최적화
- **고속 조회**: MongoDB 인덱스 최적화로 빠른 조회
- **페이징 처리**: 대량 데이터 효율적 페이징
- **필터링**: 카테고리, 브랜드, 가격대별 필터
- **정렬**: 다양한 기준의 정렬 지원

### 2. 공모 상품 조회
- **공모 목록**: 진행 중인 공모 상품 조회
- **공모 상세**: 공모 상세 정보 및 진행률
- **찜한 공모**: 사용자별 관심 공모 조회
- **공모 상태**: 실시간 공모 진행 상태

### 3. 조각 상품 조회
- **조각 목록**: 거래 가능한 조각 상품 조회
- **시세 정보**: 현재 조각 가격 및 변동률
- **거래 내역**: 조각 거래 기록 조회
- **보유 현황**: 사용자별 조각 보유 정보

### 4. 검색 및 필터
- **키워드 검색**: 상품명, 브랜드명 검색
- **카테고리 필터**: 카테고리별 상품 필터링
- **가격대 필터**: 가격 범위별 필터링
- **상태별 필터**: 상품 상태별 필터링

## ⚙️ 환경 설정

### 필수 요구사항
- Java 17 이상
- MongoDB 4.4 이상
- Redis 7.0 이상
- Docker (선택사항)

### 환경 변수
- **MONGODB_URI**: MongoDB 연결 정보
- **REDIS_URL**: Redis 서버 연결 정보
- **KAFKA_BOOTSTRAP_SERVERS**: Kafka 서버 정보
- **EUREKA_CLIENT_SERVICE_URL**: Eureka 서버 정보

## 📚 API 문서

### Swagger UI 접속
API 문서는 Swagger UI를 통해 확인할 수 있습니다.

### 주요 API 엔드포인트

#### 상품 조회
- **상품 목록 조회**: 전체 상품 목록 조회 (페이징, 필터링)
- **상품 상세 조회**: 특정 상품의 상세 정보 조회
- **인기 상품 조회**: 인기도 기준 상품 목록
- **신규 상품 조회**: 최신 등록 상품 목록

#### 공모 조회
- **공모 목록 조회**: 진행 중인 공모 목록
- **공모 상세 조회**: 공모 상세 정보 및 참여 현황
- **인기 공모 조회**: 인기 공모 순위
- **마감 임박 공모**: 마감이 임박한 공모 목록

#### 조각 조회
- **조각 목록 조회**: 거래 가능한 조각 목록
- **조각 상세 조회**: 조각 상세 정보 및 시세
- **HOT 조각**: 거래량 기준 인기 조각
- **수익률 순위**: 수익률 기준 조각 순위

#### 검색 기능
- **통합 검색**: 상품, 공모, 조각 통합 검색
- **자동완성**: 검색어 자동완성 제안
- **검색 기록**: 사용자별 검색 기록
- **인기 검색어**: 실시간 인기 검색어
